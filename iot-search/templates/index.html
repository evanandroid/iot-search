Cara kerja mesin pencari

  1. Pra-proses case folding, cleaning, tokenizing, stopword removal, stemming.
  2. Indeksasi membangun inverted index: term → dokumen beserta frekuensinya.
  3. Pembobotan w = (1 + log₁₀ tf) × log₁₀(N / df)
  4. Perangkingan cos(q, d) = (q·d) / (|q| |d|)
